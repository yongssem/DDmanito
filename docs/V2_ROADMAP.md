# 뚝딱마니또 v2 로드맵

## 시작 deadline
v1 인디스쿨 첫 게시 후 2주 이내

## 핵심 목표
"매칭 도구" → "한 달간의 이벤트"

## 데이터 구조 변경
기존: `{ c, m }`
신규: `{ c, m, r }`
- `r`: revealAt (Unix timestamp, 공개일)

## 핵심 기능 5개

1. **공개일 설정** — TeacherSetup에 날짜 입력 추가
2. **카운트다운** — StudentReveal 진입 시 D-day 표시
3. **매일 미션** — 30개 고정 미션 배열, D-day로 인덱싱
4. **자동 잠금** — 공개일 전에는 마니또 이름 안 보임
5. **공개의 날 연출** — 진입 즉시 자동 폭죽 + 큰 등장

## 미션 콘텐츠 작성 필요

30개 미션 (D-30 ~ D-1). 예시:
- D-30: 마니또에게 미소 짓기
- D-25: 마니또 자리 정리해주기
- D-20: 마니또 이름 마음속으로 부르기
- ...
- D-1: 내일이면 만나요. 마지막 응원 보내기

## 영향 받는 파일

- `src/lib/encode.js` — 스키마 변경 (`r` 필드 추가)
- `src/pages/TeacherSetup.jsx` — Step 2와 Step 3 사이에 날짜 선택 추가
- `src/pages/StudentReveal.jsx` — `now < r`이면 잠금 화면, 아니면 공개
- `src/lib/missions.js` — 신규. 30개 미션 배열 + D-day → 미션 매핑 함수
- `src/pages/Home.jsx` — v2 예고 카드를 정식 기능 카드로 교체

## UX 분기 설계

```
StudentReveal 진입
  ├─ data.r 없음 → v1 동작 (즉시 공개)
  └─ data.r 있음
       ├─ now < r → 잠금 화면
       │           ├─ D-day 카운트다운
       │           ├─ 오늘의 미션 표시
       │           └─ "마니또는 N월 N일에 공개돼요"
       └─ now >= r → 공개 화면
                   ├─ 진입 즉시 자동 폭죽
                   └─ 기존 reveal 연출
```

이 분기로 v1과 v2 링크 모두 호환 (v1 링크는 `r` 필드가 없으니 즉시 공개).
