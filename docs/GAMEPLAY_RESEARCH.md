# 게임·메타버스 사례와 뚝딱마니또 적용

조사일: 2026-11-02. 아래는 공식 서비스와 공식 발표에서 확인한 사례이며, 시장 점유율을 조사한 통계 보고서는 아니다.

## 1. 일일 퀘스트와 작은 달성 보상

Duolingo는 2025년 제품 정리에서 일일 퀘스트 보상과 친구 퀘스트 매칭, 달성 애니메이션을 설명한다. 반복 방문과 작은 성공을 명확히 보여주는 사례다.

- 출처: [2025 Duolingo Highlights](https://blog.duolingo.com/product-highlights/)
- 적용 판단: 마니또의 친절 행동을 오늘의 미션으로 제시하고 완료 도장을 남긴다. 누적 실천에 따라 개인 배지와 지도를 변화시킨다.
- 이번 적용: 오늘의 미션, 완료 도장, 누적 성장 배지, 5개 장소의 탐험 여권.
- 설계 선택: 순위·공개 점수 경쟁 대신 개인 실천을 보여준다. 하루를 놓쳐도 기록을 초기화하지 않는다.

## 2. 작은 세계관과 학급 협동 공간

ClassDojo의 교사용 Dojo Islands는 학급 전용 섬, 함께 만드는 공간, 협동 과제와 정해진 채팅을 안내한다. 별도의 모험 소개에서는 NPC가 주는 일일 퀘스트와 개인 섬 꾸미기를 보여준다. 가정용·공개 플레이와 교실용 기능을 구분해서 참고했다.

- 출처: [Dojo Islands for Teachers](https://www.classdojo.com/dojo-islands/teachers/)
- 출처: [Dojo Islands: Adventure Starts Here](https://www.classdojo.com/en-gb/dojo-islands/)
- 적용 판단: ‘비밀 친구 탐험’이라는 세계관과 작은 지도는 기존 마니또 활동에도 자연스럽게 붙는다. 학급 공동 마을은 교사 집계가 생겼을 때 함께 설계한다.
- 이번 적용: 시작 캠프 → 미소 숲 → 배려 정원 → 응원 다리 → 우정 마을. 실시간 공간 이동 기능은 아니다.
- 후속 후보: 실천을 모아 학급 정원에 꽃이 피는 공동 목표, 간단한 개인 아바타와 꾸미기.

## 3. 지속되는 공유 세계와 교사 운영 도구

Minecraft Education은 2026년 4월 Nord Anglia 사례에서 여러 학교가 같은 세계에 접속해 공동 과제를 수행하는 방식을 소개한다. Dedicated Server와 교사·관리자 운영을 함께 설명한다.

- 출처: [New Dedicated Servers power global collaboration for Nord Anglia schools](https://education.minecraft.net/da-dk/blog/nord-anglia)
- 적용 판단: 함께 만드는 세계는 협동 활동에 어울리지만, 계정·교실 구분·연결 복구·기기 성능·교사 운영이 추가된다. 현재의 개인 QR 기능에 3D 엔진부터 넣을 필요는 적다.
- 후속 후보: 교사 호스트가 있는 작은 2D 교실 마을을 먼저 검토한다. 실시간 동기화가 있어야 학생들의 공동 성장을 표시할 수 있다.

## 추천 순서

| 단계 | 요소 | 상태 / 필요한 작업 |
| --- | --- | --- |
| 지금 | 일일 퀘스트, 도장, 배지, 개인 탐험 지도 | 이번 구현에 포함 |
| 다음 | 간단한 아바타와 꾸미기, 학급 공동 정원 | 아바타 선택·연결 및 집계 설계 필요 |
| 확장 | 함께 이동하는 2D 교실 마을 | 교사 호스트, 교실별 연결, 복구·동기화 필요 |
| 별도 프로젝트 | 자유 이동형 3D 메타버스 | 렌더링·멀티플레이·운영 도구를 별도 검증 |

성공 기준은 화면 안에 오래 머무는 시간보다 **실제 교실에서 친구에게 친절을 실천하는가**에 둔다. 돈·선물·소지품 접촉을 요구하지 않고, 상대의 의사를 존중하는 짧은 행동을 미션으로 구성했다.
