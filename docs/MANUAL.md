# 사용설명서 관리

- `public/manual.html`: Paperlogy 500·800과 아이콘을 data URI로 포함한 독립 HTML. 글꼴 OFL 전문 포함. A4 세로, 페이지별 break-after와 인쇄 전용 여백을 적용한다.
- `public/manual.pdf`: 같은 안내 내용을 담은 A4 2쪽 인쇄본. ReportLab과 Windows 맑은 고딕을 사용하므로 HTML의 브라우저 출력과 글꼴·세부 배치는 다르다.
- HTML과 PDF의 안내 내용·버전·날짜는 함께 갱신한다. PDF를 다시 만들면 두 페이지를 렌더링해 잘림과 한글을 확인한다.
- 공통 앱 도구의 ‘사용설명서 / PDF’가 새 탭에서 HTML을 연다. 기존 활동 화면은 유지한다.
- HTML의 ‘인쇄 / PDF 저장’은 document.fonts.ready 후 window.print를 호출한다. 브라우저 자체 인쇄를 지원하지 않는 환경에는 PDF 직접 다운로드를 제공한다.

1.1.2 검증: PDF 2쪽·A4·한글 텍스트 확인, 두 페이지 PNG 시각 검수. HTML의 두 페이지 내용과 링크 확인. 실제 Chrome 인쇄 미리보기는 자동화 중 응답이 멈춰 저장까지 확인하지 못했으며 해당 테스트 탭은 닫았다. 일반 브라우저 인쇄는 환경에 따라 여백·배경 그래픽 설정이 다를 수 있다. PDF 인쇄본을 직접 사용하면 페이지 구성이 고정된다. 실제 종이 인쇄는 미확인.
