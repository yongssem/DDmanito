# 뚝딱마니또 (DdakManito)

서버 0, 회원가입 0, 개인정보 0인 학급 마니또 앱.

## 사용법

1. 선생님: 학급 만들기 → 학생 명단 입력 → 매칭
2. 매칭 완료 후 생성된 링크를 학생들에게 카톡/QR로 전달
3. 학생: 링크 접속 → 자기 이름 클릭 → 마니또 공개 🎁

## 기술 스택

React + Vite + Tailwind + Framer Motion + tsparticles
서버/DB 없이 URL 압축으로 데이터 전달 (lz-string)
