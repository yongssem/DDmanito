# 뚝딱마니또 v2 구현 범위

## 이번에 구현한 기능

- 학생별 QR·개인 링크, 인쇄용 초대장과 복사 기능
- 교사 브라우저에 명단 보관, 최근 QR 목록 재접속
- 엑셀 명단 붙여넣기, 적용 전 미리보기, 결번·동명이인 지원
- 시작일·마지막 날 설정(1~60일), 한국 시간 기준의 날짜 계산
- 하루 한 개의 고정 미션, 마지막 날 감사 인사, 시작 전·종료 후 상태
- 비밀 친구 탐험 지도, 실천 도장, 성장 배지
- 기존 링크 경로 호환

## 날짜와 공개의 의미

학생은 QR을 받은 직후 **내가 챙겨줄 친구**를 확인할 수 있다. 미션은 활동 시작일부터 열린다. 마지막 날은 활동 종료일이며 **나를 챙겨준 친구**의 자동 공개일이 아니다. 이전 계획의 `now < revealAt` 이름 잠금은 실제 미션 수행과 맞지 않아 사용하지 않는다.

## 데이터 흐름

교사 입력 → 브라우저 저장 → 학생 한 쌍만 분리 → `/s#학생데이터` QR → 학생 미션 → 학생 브라우저 도장 저장.

교사용 자료는 `/teacher/share/:activityId`에서 같은 브라우저의 저장 데이터를 읽는다. 학생 링크에는 다른 학생 명단이나 나를 챙겨주는 친구 정보를 넣지 않는다. 기존 공통 링크는 별도 경로로 유지한다.

## 후속 검토 대상

- 교사 승인 후 마지막 날 전체 정체 공개
- 교사 호스트·교실별 연결을 통한 실천 현황 집계와 공동 마을 성장
- 학생 아바타와 꾸미기 아이템
- 기기 간 기록 동기화·개인 링크 회수

실시간 협동·메타버스는 별도 연결 구조가 필요한 후속 기능이다. 이번 버전의 탐험 지도는 개인 도장에 따라 이동하는 2D 진행 표시다.
