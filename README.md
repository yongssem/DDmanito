# 무무마니또 · 비밀 친구 탐험

학생별 QR 초대장과 오늘의 미션으로 진행하는 학급 마니또 웹앱입니다.
React + Vite + Tailwind CSS. 회원가입이나 별도 데이터베이스 없이 동작합니다.

## 선생님 사용법

1. 학급 이름과 활동 기간(1~60일, 시작일·마지막 날 포함)을 정합니다.
2. 엑셀에서 **이름 한 열** 또는 **출석번호·이름 두 열**을 복사해 명단 입력란에 붙여넣습니다.
3. 미리보기 인원을 확인하고 **붙여넣은 명단 적용**을 누릅니다. 적용 전 명단은 덮어쓰지 않습니다.
4. 명단을 확인하고 매칭합니다. 결번을 유지하며 동명이인은 출석번호로 구분합니다. 최대 100명입니다.
5. 학생별 QR을 인쇄/PDF 저장하거나 개별 링크를 복사해 **해당 학생에게만** 전달합니다.
6. 홈의 **최근 QR 목록 열기**에서 마지막 활동을 다시 엽니다. 원래 만든 브라우저에서만 가능합니다.

붙여넣기 예시(열 사이는 탭):

```text
번호	이름
1	김하늘
3	김하늘
7	이바다
```

## 학생 사용법

1. 개인 QR을 열고 본인의 번호·이름을 확인합니다.
2. **내 마니또 확인하기**로 챙겨줄 친구를 확인합니다. 다시 가릴 수 있습니다.
3. 활동 시작일부터 임무 봉투를 열고, 무무가 건네는 비밀 임무를 실천한 뒤 도장을 찍습니다.
4. 탐험 여권에서 도장·성장 배지·다섯 장소의 진행 상황을 봅니다.

날짜는 **Asia/Seoul** 기준이며 달력의 모든 날에 미션이 열립니다. 시작 전에는 준비 안내, 종료 후에는 회고 화면이 나옵니다. 기본 미션 60개는 60일 동안 순서대로 제공하고 마지막 날에는 감사 인사 미션이 나옵니다. 학생별 진도는 같은 브라우저의 다른 탭에도 반영됩니다.

## 무무마니또 1.1.0

- 2030디자인 A안: 로컬 페이퍼로지, 크림색 종이, 짙은 윤곽선, 청록색 하드 섀도.
- 학교 태블릿·PC에서는 친구 정보, 오늘의 미션, 활동 지도를 넓게 배치합니다. 작은 화면에서는 세로로 접힙니다.
- 탐험대장 무무는 24프레임 대기 호흡과 4프레임 걷기를 사용합니다. 움직임 줄이기와 비활성 탭 정지도 지원합니다.
- 공식 주소 공유·복사, 기기별 설치 안내, 전체화면과 고정 나가기 버튼을 제공합니다.
- 설치 창이 가능한 브라우저에서는 실제 설치 창을 엽니다. 인터넷이 필요하며 오프라인 캐시는 제공하지 않습니다.
- 무무마니또 첫 정식 배포일은 2026-11-02(한국 시간)입니다. 버전·배포일·변경 기록은 `src/lib/releases.js`에서 관리합니다.
- 명단 없이 `/demo`에서 학생 미션을 체험할 수 있습니다. 체험 도장은 실제 활동과 분리됩니다.
- 오늘의 임무 봉투를 열고 실천하면 친절 도장과 캐릭터 축하가 나옵니다.
- 교사 QR 배부 화면에 학생용 안내문 보기·복사 기능이 있습니다.
- 학교 태블릿 또는 폰으로 잠깐 확인하고 교실에서 실천합니다. 집에서 접속할 필요는 없습니다.
- 미션은 같은 기기로 이어서 참여합니다. 실시간 공동 접속 공간은 포함하지 않습니다.
- 이미지 제작 프롬프트는 `docs/IMAGE_PROMPTS.json`, 폰트 라이선스는 `public/fonts/Paperlogy-OFL.txt`에 있습니다.

## 데이터와 비밀 유지

- 교사용 전체 명단·매칭은 해당 브라우저의 `localStorage`에 저장합니다. `/teacher/share/:activityId` 주소에 전체 명단을 넣지 않습니다.
- 학생 URL은 `/s#...` 형태이며 본인·챙겨줄 친구 한 쌍, 학급, 기간, 활동 식별자만 압축해 담습니다. URL 조각은 웹 서버 요청에 포함되지 않습니다.
- **압축은 암호화가 아닙니다. 링크 소지자는 결과를 볼 수 있으며 본인 인증·링크 회수 기능은 없습니다.** QR 전체를 단체방에 공유하지 마세요.
- 도장도 학생 브라우저에 저장됩니다. 다른 기기와 동기화하거나 교사가 집계하지 않습니다. 사이트 데이터를 지우면 기록이 없어집니다.
- 공용 PC에서는 사용 후 사이트 데이터를 삭제하세요. 삭제 전에 교사용 QR 목록을 인쇄/PDF로 보관하세요. 배부한 학생 링크는 교사 데이터 삭제와 무관하게 계속 동작합니다.
- 기존 `/r/:encoded`, `/share/:encoded` 공통 링크는 호환을 위해 유지합니다. 이 링크들은 예전의 전체 명단·매칭 전달 방식입니다. 새로운 활동은 학생별 QR로 만드세요.
- 활동 마지막 날은 **활동 종료일**입니다. 나를 챙겨준 친구를 자동 공개하지 않습니다. 정체 공개는 교사 안내로 진행합니다.
